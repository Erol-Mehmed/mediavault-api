# MediaVault API

Backend API for MediaVault — a media tracking system for movies, TV shows, anime, games, and more.

## Tech Stack
- NestJS
- TypeScript
- PostgreSQL (via Knex)
- JWT Authentication
- bcrypt

## Features
- User authentication (login, refresh, logout)
- JWT access & refresh token system
- Media CRUD (create, update, delete, fetch)
- Per-user media lists
- Unit-tested services
